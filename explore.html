Credit Risk Modelling – Deployed Model

Created and deployed an end-to-end Machine Learning model to evaluate probability of default (PD) for loan applicants.

  • Methodology: Logistic Regression, XGBoost classification, and WoE (Weight of Evidence) binning.
  • Deployment: Served the model via a Python-based REST API (using FastAPI/Streamlit) to provide real-world credit risk assessment scoring.
Key Outcome: Integrated credit scoring metrics into a clean front-end, reducing test assessment time by 40% while preserving strict regulatory standards.
